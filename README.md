# Silverstripe user documentation module

[![CI](https://github.com/silverstripe/silverstripe-userdocs-admin/actions/workflows/ci.yml/badge.svg)](https://github.com/silverstripe/silverstripe-userdocs-admin/actions/workflows/ci.yml)
[![Silverstripe supported module](https://img.shields.io/badge/silverstripe-supported-0071C4.svg)](https://www.silverstripe.org/software/addons/silverstripe-commercially-supported-module-list/)

This module provides an admin section which renders out markdown documentation for content authors and other users of the CMS.

Documentation for all commercially supported modules that are installed for the project will populate automatically. Documentation can also be added for third part modules and the project itself.

## Installation

```sh
composer require silverstripe/userdocs-admin
```
