# User documentation

## Introduction

This module provides a help section inside the CMS to display documentation for content authors.

Documentation should be bundled with the modules themselves. For example, user documentation for the `silverstripe/admin` module is included when that module is installed. Projects can also provide additional documentation, and all documentation pages can be replaced if needed to indicate updated functionality.

For a more detailed overview of using this module, please see [the User help guides](docs/en/userguide/index.md).

## Installation

```bash
composer require silverstripe/silverstripe-userdocs-admin
```
